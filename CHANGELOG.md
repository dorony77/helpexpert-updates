# Список изменений Helpexpert

Формат: новые версии сверху. Ведётся автоматически при каждой публикации
обновления (см. `D:\helpexpert-updates\publish_exe.bat`) - текст верхней
секции попадает в `exe_manifest.json` и показывается эксперту в диалоге
"Доступно обновление" ДО того, как он решит обновляться.

---

## 1.0.11 (2026-10-06)

Fix: программа брала цену не того производителя на трёх площадках.
- **Автодок, кнопка «Найти код Автодока»:** Автодок отдаёт всех
  производителей, у кого есть этот номер (оригинал и аналоги), а
  подставлялся первый — например, для Hyundai/Kia аналог HANON (9166)
  или DAR (7761) вместо оригинала HYUNDAI | KIA (647). Теперь
  выбирается производитель по марке из поля «Предпочитаемый
  производитель», а если марка не указана — оригинал (автомарка); если
  однозначно не определилось — программа спросит, а не угадает.
- **Emex:** номер с пробелами («16 742 484 80») открывал страницу
  первого попавшегося производителя (General Motors), и бралась его
  цена. Теперь номер отправляется слитно, для Peugeot/Citroën сразу
  открывается страница «Peugeot / Citroën», а если всё же открылся
  чужой производитель — цена чужого не берётся (записывается «нет
  предложения»). Марка «CITROEN» теперь узнаёт «Citroën».
- **Exist:** окно «Выберите каталог» не выбиралось для марки PEUGEOT
  (искали только в начале строки «Citroen/Peugeot…»). Теперь марка
  ищется в каждой части объединённого названия (Citroen/Peugeot,
  Fiat/Alfa/Lancia), с учётом псевдонимов (Opel → General Motors).

## 1.0.10 (2026-10-01)

Fix (повторно): «актуальные номера» на вкладке «Актуальность номеров»
снова пропадали после правки артикула прямо в таблице результатов -
точечный фикс от 29.09.2026 закрывал только кнопку «Заменить номера»,
баг вернулся через другой путь (та же функция-источник
`fill_actual_table()` вызывается из множества мест). Сохранение/
восстановление уже найденных номеров перенесено в сам источник - по
артикулу, не по позиции строки, работает независимо от того, что
именно вызвало пересборку.

## 1.0.9 (2026-10-01)

Fix: правка каталожного номера прямо в таблице результатов ("Сбор
цен") могла увести артикулы ДРУГИХ, не редактируемых строк. Причина -
два связанных бага:
- "Забрать цены из корзины" могла добавить в таблицу новую строку
  (предложение из реальной корзины под номером, которого ещё нет в
  собранном перечне) без соответствующей записи в служебном списке
  деталей - таблица и список расходились по длине.
- Правка номера читала "старое" значение по ПОЗИЦИИ строки в этом
  списке, а не по содержимому - при расхождении правка попадала в
  чужой слот, молча портя артикул другой, нетронутой строки.

Оба источника устранены: список деталей теперь всегда синхронен с
таблицей, а правка ищет нужную запись по имени строки, а не по
позиции.

## 1.0.8 (2026-10-01)

Fix: "Забрать цены из корзины" при повторяющемся каталожном номере в
перечне (реальный случай - "диск передний"/"диск задний" под одним
номером) всегда находила и перезаписывала только ПЕРВУЮ строку с этим
артикулом - вторая (и любая следующая) строка с тем же номером никогда
не получала цену ни для одной площадки, оставаясь на "..." навсегда.
Воспроизведено минимальным тестом перед фиксом.

## 1.0.7 (2026-10-01)

Fix: ручной захват цены по CAPS LOCK не работал после вчерашней
реорганизации вкладок (1.0.5) - проверка индекса внутренней вкладки
осталась со старыми номерами. CAPS LOCK на вкладке "Сбор цен" (где
теперь реально открыт браузер) не делал ничего, а на "Актуальность
номеров" срабатывал неверный обработчик. Индексы поправлены под новую
раскладку вкладок.

## 1.0.6 (2026-10-01)

Техническая пересборка: синхронизированы VERSION.txt/CHANGELOG.md в
основном репозитории (D:\makchudak) с тем, что уже было опубликовано
как 1.0.5 - расхождение возникло, когда версия для сборки 1.0.5
поднималась отдельно от этих файлов. Изменений в коде программы
относительно 1.0.5 нет.

## 1.0.5 (2026-09-30)

- Вкладка "Агрегаторы" реорганизована: рабочая таблица сбора цен и
  управление (кнопки ЗАПУСТИТЬ/ПАУЗА/ОСТАНОВИТЬ и т.п.) вынесены в
  отдельную вкладку "Сбор цен", рядом с "Агрегаторы". Блок "Ввод
  деталей и выбор площадок" теперь рядом с "Данные дела", а не под
  ним. Браузер виден только на вкладке "Сбор цен" - больше места под
  остальные вкладки.
- Несколько фиксов раскладки окна вслед за этой реорганизацией (браузер
  не сжимался/не растягивался как надо при переключении вкладок).
- Высота строк таблицы сбора цен уменьшена на 20% - больше деталей
  видно без прокрутки.
- Публикация обновлений программы теперь подписывается (Ed25519) -
  защита от подмены exe при компрометации репозитория обновлений,
  поверх уже существующей проверки контрольной суммы.

## 1.0.4 (2026-09-29)

Fix: подмена exe при самообновлении 1.0.2 -> 1.0.3 отработала правильно
(бинарник реально заменился), но VERSION.txt/CHANGELOG.md рядом
оставались от старой сборки - программа физически была уже новой
версии, но продолжала ПОКАЗЫВАТЬ старый номер ("не обновляется", хотя
по факту обновилось). Хелпер обновления теперь подменяет VERSION.txt
(из манифеста, без отдельного скачивания) и CHANGELOG.md (best-effort
скачивание) вместе с exe, одним атомарным шагом.

## 1.0.3 (2026-09-29)

Три фикса реальных живых багов, найденных сразу после выхода 1.0.2.

- АвтоТО: добавлен алиас марки Nissan/Infiniti - детали, общие для
  концерна, раньше не принимались (реальный производитель предложения
  указан как "Infiniti", хотя искали "Nissan"), теперь принимаются
  корректно.
- El-Zap: при неудачной загрузке страницы во время паузы автоматики
  программа переставала откатывать страницу на URL последней
  автоматической навигации. Раньше это выглядело так, будто программа
  сама "вставляет номер" поверх того, куда эксперт зашёл вручную.
- Юлсун: подлинное "ничего не найдено" на сайте ошибочно ставило
  программу на паузу с предупреждением про корзину (использовался тот
  же сигнал, что настоящая гонка с подтверждением корзины) - теперь
  пишется 0 без лишней паузы.

## 1.0.2 (2026-09-29)

Критический фикс самой механики самообновления - обнаружено при первой
живой попытке обновиться с 1.0.0 на 1.0.1: подмена файла не сработала,
программа не переоткрылась.

- Fix: `sys.executable` в сборке Nuitka возвращал "python.exe" вместо
  реального "Helpexpert.exe" - хелпер обновления пытался подменить не
  тот файл. Заменено на WinAPI GetModuleFileNameW - надёжный источник
  пути к реально запущенному exe.
- Fix: хелпер обновления запускался без консоли вообще (DETACHED_PROCESS),
  из-за чего использованные внутри него `timeout`/`tasklist`/`find`
  переставали работать. Заменено на CREATE_NO_WINDOW - консоль есть,
  просто скрыта.
- Fix: ожидание закрытия программы только по PID уязвимо к
  переиспользованию PID Windows-ом (актуально для этой программы -
  много короткоживущих дочерних процессов QtWebEngineProcess.exe).
  Добавлена проверка по PID И имени процесса одновременно, плюс
  защитный потолок ожидания (30с), чтобы хелпер не мог зависнуть молча
  навсегда.

## 1.0.0 (2026-09-29)

Первый выпуск с самообновлением - весь список ниже относится к правкам
за 29.09.2026, до этого версии не публиковались.

- Автообновление программы без полной переустановки через Inno Setup
  (меню "Справка" → "Проверить обновление программы...") - проверка
  версии, скачивание, сверка контрольной суммы, автоматический
  перезапуск.
- Перед самообновлением дело сохраняется явно и восстанавливается на
  новом запуске без лишних вопросов.
- Фикс: на вкладке "Актуальность номеров" кнопка "Заменить номера"
  стирала весь столбец с найденными актуальными номерами вместо того,
  чтобы просто заменить устаревшие.
- Автодок: убран резервный поиск по коду концерна (VAG/GM) - теперь
  работает строго по введённому коду, без лишних попыток.
- Автодок: добавлен поиск точного кода производителя по каталожному
  номеру напрямую через API Автодока (поле + кнопка "Найти код
  Автодока"), взамен угадывания по марке.
- Юлсун: номер офиса вынесен в настраиваемое поле (было жёстко зашито
  "190"/Краснодар) - можно передать программу другому эксперту с другим
  офисом без правки кода.
- Всплывающие подсказки на ключевых полях блока "Данные дела" +
  переключатель "Показывать подсказки" (меню "Справка").
