# Список изменений Helpexpert

Формат: новые версии сверху. Ведётся автоматически при каждой публикации
обновления (см. `D:\helpexpert-updates\publish_exe.bat`) - текст верхней
секции попадает в `exe_manifest.json` и показывается эксперту в диалоге
"Доступно обновление" ДО того, как он решит обновляться.

---

## 1.0.4 (2026-09-29)

Fix: подмена exe при самообновлении 1.0.2 -> 1.0.3 отработала правильно
(бинарник реально заменился), но VERSION.txt/CHANGELOG.md рядом
оставались от старой сборки - программа физически была уже новой
версии, но продолжала ПОКАЗЫВАТЬ старый номер ("не обновляется", хотя
по факту обновилось). Хелпер обновления теперь подменяет VERSION.txt
(из манифеста, без отдельного скачивания) и CHANGELOG.md (best-effort
скачивание) вместе с exe, одним атомарным шагом.

## 1.0.3 (2026-09-29)

Три фикса реальных живых багов, найденных сразу после выхода 1.0.2.

- АвтоТО: добавлен алиас марки Nissan/Infiniti - детали, общие для
  концерна, раньше не принимались (реальный производитель предложения
  указан как "Infiniti", хотя искали "Nissan"), теперь принимаются
  корректно.
- El-Zap: при неудачной загрузке страницы во время паузы автоматики
  программа переставала откатывать страницу на URL последней
  автоматической навигации. Раньше это выглядело так, будто программа
  сама "вставляет номер" поверх того, куда эксперт зашёл вручную.
- Юлсун: подлинное "ничего не найдено" на сайте ошибочно ставило
  программу на паузу с предупреждением про корзину (использовался тот
  же сигнал, что настоящая гонка с подтверждением корзины) - теперь
  пишется 0 без лишней паузы.

## 1.0.2 (2026-09-29)

Критический фикс самой механики самообновления - обнаружено при первой
живой попытке обновиться с 1.0.0 на 1.0.1: подмена файла не сработала,
программа не переоткрылась.

- Fix: `sys.executable` в сборке Nuitka возвращал "python.exe" вместо
  реального "Helpexpert.exe" - хелпер обновления пытался подменить не
  тот файл. Заменено на WinAPI GetModuleFileNameW - надёжный источник
  пути к реально запущенному exe.
- Fix: хелпер обновления запускался без консоли вообще (DETACHED_PROCESS),
  из-за чего использованные внутри него `timeout`/`tasklist`/`find`
  переставали работать. Заменено на CREATE_NO_WINDOW - консоль есть,
  просто скрыта.
- Fix: ожидание закрытия программы только по PID уязвимо к
  переиспользованию PID Windows-ом (актуально для этой программы -
  много короткоживущих дочерних процессов QtWebEngineProcess.exe).
  Добавлена проверка по PID И имени процесса одновременно, плюс
  защитный потолок ожидания (30с), чтобы хелпер не мог зависнуть молча
  навсегда.

## 1.0.0 (2026-09-29)

Первый выпуск с самообновлением - весь список ниже относится к правкам
за 29.09.2026, до этого версии не публиковались.

- Автообновление программы без полной переустановки через Inno Setup
  (меню "Справка" → "Проверить обновление программы...") - проверка
  версии, скачивание, сверка контрольной суммы, автоматический
  перезапуск.
- Перед самообновлением дело сохраняется явно и восстанавливается на
  новом запуске без лишних вопросов.
- Фикс: на вкладке "Актуальность номеров" кнопка "Заменить номера"
  стирала весь столбец с найденными актуальными номерами вместо того,
  чтобы просто заменить устаревшие.
- Автодок: убран резервный поиск по коду концерна (VAG/GM) - теперь
  работает строго по введённому коду, без лишних попыток.
- Автодок: добавлен поиск точного кода производителя по каталожному
  номеру напрямую через API Автодока (поле + кнопка "Найти код
  Автодока"), взамен угадывания по марке.
- Юлсун: номер офиса вынесен в настраиваемое поле (было жёстко зашито
  "190"/Краснодар) - можно передать программу другому эксперту с другим
  офисом без правки кода.
- Всплывающие подсказки на ключевых полях блока "Данные дела" +
  переключатель "Показывать подсказки" (меню "Справка").
